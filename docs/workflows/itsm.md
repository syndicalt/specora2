# ITSM Workflows

Specora includes native ITSM applications that use CMDB context, AI assistance, and platform records.

## Incident Command Center

![Incident Command Center](../screenshots/incident-command-center.png)

Use Incident Command Center to:

- Review high-priority incidents.
- Triage impact and severity.
- Connect incidents to affected CIs or services.
- Draft remediation steps.
- Support major incident command.

## Change Manager

![Change Manager](../screenshots/change-manager-overview.png)

Use Change Manager to:

- Create and review change requests.
- Prepare CAB context.
- Track approval readiness.
- Apply state-machine governed status changes.
- Link changes to services, CIs, and risks.

## Knowledge Core

![Knowledge Core](../screenshots/knowledge-core-overview.png)

Use Knowledge Core to:

- Search governed operational knowledge.
- Review knowledge gaps.
- Draft articles from incidents and changes.
- Publish or retire knowledge.
- Track confidence and feedback.

## Prevention Center

![Prevention Center](../screenshots/prevention-center-overview.png)

Use Prevention Center to:

- Identify recurring incident patterns.
- Track known errors.
- Propose corrective actions.
- Measure reliability improvement.

## Asset Command Center

![Asset Command Center](../screenshots/asset-command-center.png)

Use Asset Command Center to:

- Review hardware custody and asset exceptions.
- Reconcile software entitlements.
- Inspect contract and license signals.
- Identify financial and compliance risk.

## Customer Portal

![Customer Portal](../screenshots/customer-portal-home.png)

Use Customer Portal as the requester front door for:

- Knowledge deflection.
- Catalog requests.
- Request status.
- Support handoffs.

## Engage Agent Workspace

![Engage Agent Workspace](../screenshots/engage-agent-workspace.png)

Use Engage Agent Workspace to:

- Review catalog request queues.
- Prepare agent briefs.
- Draft requester updates.
- Link requests to knowledge, users, and operational records.

## Chat Assistance

Chat can support ITSM workflows by:

- Summarizing current record context.
- Drafting action plans.
- Explaining CI impact.
- Opening related apps.
- Recommending next steps from available platform context.
