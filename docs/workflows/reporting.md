# Reporting

Reporting provides operational dashboards, governed report previews, and exportable data for analytics workflows.

![Reporting dashboard](../screenshots/reporting-dashboard.png)

## Use Reporting To

- Review platform KPIs.
- Inspect operational health indicators.
- Preview report datasets.
- Export governed report data.
- Support downstream BI or executive reporting.

## Common Reports

Available report categories may include:

- CMDB completeness.
- Discovery freshness.
- Relationship coverage.
- Incident performance.
- Change readiness.
- Knowledge gaps.
- Asset exceptions.
- Platform administration signals.

## Export

Use export options when available to download:

- CSV.
- JSON.

Exports should respect role-based permissions and report scope.

## BI Handoff

Reporting is intended to support a governed BI contract:

- Stable metrics.
- Clear definitions.
- Traceable source data.
- Consistent time windows.
- Role-aware access.
