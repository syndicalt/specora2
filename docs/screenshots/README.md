# Screenshot Catalog

Screenshots make the guides useful for admins, operators, and evaluators. Keep images current with the UI.

## Capture Rules

- Use real data where possible.
- Avoid secrets, enrollment tokens, API keys, and private user data.
- Prefer 1440px or wider desktop screenshots.
- Crop only when it improves clarity.
- Use PNG for UI screenshots.
- Refresh screenshots before release tags.
