## Documentation Principles

- Document the theory behind choices, not just the mechanics.
- Distinguish implemented behavior from roadmap intent.
- Treat CSDM alignment honestly; do not imply certification.
- Keep docs useful for both humans and LLM coding agents.
- Prefer explicit file paths and data ownership boundaries.
